This app auto-connects to a shared Firebase database out of the box — no setup needed. Paste a different config below only if you want to point it elsewhere.

1ডাটা ব্যাকআপ (Export / Import)

সব ডাটা এই ব্রাউজারের localStorage-এ (এবং Firebase সংযুক্ত থাকলে সেখানেও) সেভ থাকে। নিয়মিত ব্যাকআপ নিয়ে রাখা ভালো — JSON ব্যাকআপে হুবহু ডাটা ফিরে আসে; Excel ফাইলে সব তথ্য শীট আকারে দেখা যায় (রিপোর্টের জন্য), এবং এই অ্যাপ থেকে এক্সপোর্ট করা Excel ফাইল আবার ইমপোর্টও করা যাবে।
